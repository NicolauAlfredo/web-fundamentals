# Web Fundamentals

Repository dedicated to revisiting and strengthening core front-end development concepts using HTML5 and CSS3.

The goal of this project is to continuously practice web fundamentals through structured lessons, exercises and small layouts while reinforcing clean code, semantic markup and modern styling techniques.
